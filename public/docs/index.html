Forge documentation / overview

Build agents that
can show their work.

Forge is a learning and evidence layer for agent fleets. It gives execution a verifier, gives failure a bounded repair path, and gives reflection a promotion gate.

Current boundary. The local C0 loop is verified. AO autonomous completion, second-harness transfer, and Supermemory are explicit future proof points—not features this site pretends are live.

What Forge owns

acceptanceIndependent verifier

Only a verifier-backed artifact can become a passed run.

recoveryBounded repair

One evidence-based repair path; no unbounded autonomous loop.

learningCandidate skill + gate

Reflection proposes. Applicability, A/B, and held-out checks decide.

provenanceLedger + trace

SQLite/JSONL remains authoritative; Neatlogs provides readback for the verified path.
